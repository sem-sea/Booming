Key takeaways

Structured data helps machines understand your pages: Google says it uses structured data to understand page content (Google Search Central), and Microsoft has said schema markup helps its LLMs, including Copilot (Search Engine Land, 2025). B2B sites need a small, accurate set, in the initial HTML.

Google recommends JSON-LD for structured data where your site allows it. Its documentation also lists results from sites that added markup: Rotten Tomatoes measured a 25% higher click-through rate on 100,000 pages with structured data, and Nestlé an 82% higher click-through rate for pages with rich results (Google Search Central).

Microsoft's Fabrice Canel confirmed at SMX Munich in 2025 that schema markup helps Microsoft's LLMs understand content (Search Engine Land).

Where you add it matters. In Vercel's analysis, none of the major AI crawlers rendered JavaScript, so markup injected by scripts may never be seen.

What is schema markup?

Schema markup is structured data, usually in JSON-LD, that labels what a page is about: an organization, article, person, product or service.

It does not change what visitors see. It tells crawlers, in a standard vocabulary from Schema.org, which facts on the page mean what.

Which schema types does a B2B website need?

The core schema set for a B2B website is Organization, Article or BlogPosting, Person, Product or Service, and BreadcrumbList for navigation.

How do you add schema without breaking things?

Adding schema safely means generating it from real page content, placing it in server-rendered HTML, and validating it before and after release.

  1. Start with Organization on the homepage, with consistent name, logo and profiles.
  2. Add Article and Person to posts, with real authors and accurate dates.
  3. Generate markup server-side, from your CMS or theme, not with tag managers.
  4. Mark up only what is visible on the page.
  5. Validate with the Schema Markup Validator and Google's Rich Results Test.
  6. Re-check after every redesign or plugin change.

Frequently asked questions

Does schema guarantee AI citations?

No. It helps machines understand pages; being cited still depends on content, access and authority.

Which format should we use?

JSON-LD, which Google recommends where your setup allows it.

Can a plugin handle schema?

Yes, SEO plugins such as Yoast generate core types. Check the output and avoid two plugins writing conflicting markup.

Should we add FAQ markup?

Mark up real questions and answers that are visible on the page. Do not add markup for content that is not there.

Does Google Tag Manager work for schema?

Markup injected by JavaScript may be missed by AI crawlers that do not render scripts. Server-side is safer.
