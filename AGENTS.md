# AGENTS.md — Booming Venture WordPress site

This repo hosts the Booming Venture WordPress theme (`wp-content/themes/booming-venture/`) and content seed. AI coding agents working in this repo should follow the rules below.

## Project shape

- **CMS:** WordPress 6.6+ (FSE / block theme)
- **PHP:** 8.0+
- **Theme:** `wp-content/themes/booming-venture/`
- **Block build:** vanilla JS, no transpile step (`blocks/*/view.js` ships directly)
- **Content seed:** `wp-content/themes/booming-venture/import/booming-venture-content.xml`
- **Blog builder:** `build-blog-content.py` (regenerates blog post bodies in the WXR)

## Required behaviour for content edits

GEO/AEO rules (Bible May 2026). Every blog post under `posts/` in `build-blog-content.py` and every page in the WXR import MUST:

1. **H1** contains the primary entity / keyword
2. ≥1 **question-shaped H2** (`What is …?`, `How to …?`, `Why …?`) followed within one paragraph by a **20–25 word answer capsule** starting with `[X] is …` or `[X] refers to …`
3. **≥3 statistics** with named source (link, year) inside the **first 30 % of body** (the "ski ramp", Indig Feb 2026)
4. ≥1 comparison **table** OR **ordered list ≥5 items** when topic admits one
5. JSON-LD: `Article` + `FAQPage` minimum; `HowTo` / `SoftwareApplication` / `Person` where applicable (auto-generated by `inc/seo.php` from the post body, do not hand-author)
6. **Visible "Last updated:"** banner is injected by `inc/geo.php`; do not duplicate manually
7. `sitemap.xml` lastmod auto-updates; IndexNow ping fires on publish via `inc/geo.php`

## Voice rules (always enforced)

- **No em-dashes** anywhere
- **International English**, US spelling default (organize, optimize, color)
- **No AI tells:** delve, elevate, harness, leverage, navigate, tapestry, unlock, realm, landscape, robust, seamless, foster, moreover, furthermore, "it's worth noting", "in conclusion", "in today's fast-paced world", "ever-evolving", "game-changer", "revolutionize"
- **No "It's not just X, it's Y"** construction
- Varied sentence length, fragments OK, "And"/"But" starts OK
- Specific numbers, named tools, real frameworks

## Never

- Block `OAI-SearchBot`, `Claude-SearchBot`, or `PerplexityBot` in `robots.txt` (the three-tier split in `inc/geo.php` already gets this right)
- Delete `inc/geo.php` (it ships robots.txt, llms.txt, IndexNow, extended schema, the "Last updated" banner)
- Hand-author JSON-LD; `inc/seo.php` generates it
- Use marketing-cliché filler intros
- Disable WordPress SSR; AI crawlers do not execute JavaScript

## Dev commands

```bash
# Sanity-check PHP
php -l wp-content/themes/booming-venture/inc/*.php wp-content/themes/booming-venture/functions.php

# Sanity-check the WXR
python3 -c "import xml.etree.ElementTree as ET; ET.parse('wp-content/themes/booming-venture/import/booming-venture-content.xml'); print('WXR OK')"

# Sanity-check theme.json + block.json
python3 -c "import json; [json.load(open(f)) for f in ['wp-content/themes/booming-venture/theme.json','wp-content/themes/booming-venture/blocks/funnel-calculator/block.json','wp-content/themes/booming-venture/blocks/roi-forecaster/block.json']]; print('JSON OK')"

# Regenerate all blog post bodies from build-blog-content.py
python3 build-blog-content.py

# Rebuild the installable zip
rm -f wp-content/themes/booming-venture.zip
(cd wp-content/themes && zip -rq booming-venture.zip booming-venture -x "*.DS_Store" "booming-venture/.git/*" "booming-venture/blocks/node_modules/*")
```

## Commit conventions

- Conventional Commits: `feat:` / `fix:` / `chore:` / `docs:` / `content:`
- One concern per commit. The blog rewrites in `build-blog-content.py` can be one commit per batch of ~10 posts

## Self-checking infrastructure

This repo ships its own `.claude/` configuration so Claude Code (and any AGENTS.md-aware agent) enforces these rules automatically:

- **Slash commands**: `/geo-audit`, `/optimize-passage`, `/generate-faq`, `/add-schema`, `/llms-txt`
- **Skills**: `geo-writer`, `schema-builder`, `citation-finder` (auto-invoked when matching work begins)
- **PostToolUse hook**: `.claude/hooks/post-edit-geo-check.sh` runs after every Edit / Write / MultiEdit on content files; flags banned phrases, em-dashes, and missing structural elements.

See `.claude/README.md` for the full layout. Do not delete or disable any of this without leaving the GEO/AEO compliance unprotected.
