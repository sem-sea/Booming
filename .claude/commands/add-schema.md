# Add schema — $ARGUMENTS

Schema for this site is auto-generated by `wp-content/themes/booming-venture/inc/seo.php`. Direct hand-authoring is **prohibited** by CLAUDE.md. Use this command when:

- A new page type needs a schema variant not yet covered
- A specific post needs a one-off override (rare)
- Yoast / Rank Math is active and our schema is being suppressed

## Workflow

1. Detect page type:
   - `/funnel-calculator/` or `/roi-forecaster/` → `SoftwareApplication`
   - `/blog/{slug}/` → `BlogPosting` + `FAQPage` (auto if FAQ section present) + `HowTo` (auto if title starts with "How to") + `Person` (author byline)
   - `/services/*` → `Service`
   - Sitewide → `Organization` + `WebSite` + `BreadcrumbList`
2. Read the current `inc/seo.php` to see what is already emitted.
3. If the variant is missing, add it inside the existing `add_action( 'wp_head', ... )` block in `inc/seo.php`, gated by `is_page(...)` or `is_singular(...)`.
4. Fill every required property with **real values pulled from the page**, never placeholders.
5. Cross-link entities with `@id` (e.g. `Article.publisher → Organization @id`).
6. Use ISO 8601 dates with timezone.
7. After saving, run:
   ```bash
   php -l wp-content/themes/booming-venture/inc/seo.php
   ```
8. Validate the emitted schema on a deployed page:
   ```bash
   curl -s $URL | grep -A 500 'application/ld+json'
   ```
   Then paste into <https://validator.schema.org/>.

## Never

- Hand-write schema directly into a pattern file or block template.
- Skip the `@id` cross-link — it is what makes the schema graph (vs unconnected blobs).
- Emit schema for a page type that does not match its content (e.g. `Product` on a blog post).
- Duplicate Organization / WebSite when Yoast or Rank Math is active — the `bv_seo_active_plugin_handles_meta()` guard already handles this.

## Person schema additions

For an author bio, edit the user in WP admin (`Users → All Users → [name]`) and fill:

- `linkedin` (or `user_url`) user_meta
- `twitter` user_meta
- `github` user_meta
- `scholar` user_meta

These are picked up automatically by `inc/seo.php` and added to the Person `sameAs` array.
